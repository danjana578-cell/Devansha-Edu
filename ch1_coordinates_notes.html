Section 1.1 — History & Background
Coordinates ki kahani — Bhārat se Descartes tak

Coordinates ka idea bohot purana hai. Ye sirf math ki theory nahi hai — yeh ek practical tool hai jo hamare ancestors ne thousands of years pehle use kiya tha, actual cities banane mein, navigation mein, aur astronomy mein.

🌟 Interesting Fact — Dil ko Chhu Jane Wali Baat

Tumhara apna sheher Bhopal, Madhya Pradesh bhi coordinates ke zariye map par locate hota hai! Latitude 23.26°N aur Longitude 77.40°E — ye coordinates hi batate hain ki Bhopal duniya mein exactly kahan hai. Aaj jo seekhoge, woh same system use hota hai GPS, Google Maps, satellite navigation sab mein!

Aao ek interesting sawaal se shuru karte hain: "Kisi jagah ko exactly describe kaise karein?"

Sochो — agar tumhara dost phone kare aur puchhe "Tum kahan ho?" — tum kya bologe? "Market ke paas" ya "Mandir ke left mein" — ye sab relative descriptions hain. Par agar tumhe exact location batani ho — toh tumhe coordinates chahiye!

~3000 BCE (3000 saal pehle)
🏙️ Sindhu-Sarasvatī Civilisation — Mohenjo-daro & Harappa
Duniya ki pehli grid-based city planning! Streets bilkul North–South aur East–West direction mein thi — har 10 metres ke interval par. Ye soch ke toh dekho — ek merchant apni dukan ya godown dhundh sakta tha sirf steps count karke — "5 steps East, 3 steps North" — exactly like coordinates! Yeh history ka pehla practical coordinate system tha.
~800 BCE
📐 Baudhāyana — The OG Mathematician
Baudhāyana ne East–West aur North–South lines use karke deep geometric constructions kiye. Unhone Baudhāyana–Pythagoras Theorem develop kiya — jo aaj hum "Pythagoras Theorem" bolte hain! Yahi theorem baad mein Distance Formula ka base banega.
~4th Century BCE
🌍 Ujjayinī — India's Greenwich Meridian
Ancient Siddhāntas mein Ujjayinī (aaj ka Ujjain, Madhya Pradesh) ko zero longitude ka reference point banaya gaya tha! Sari duniya ki locations yahan se measure hoti thi. Ptolemy ne bhi apni maps mein isko "Ozine" ke naam se include kiya. Interesting na — MP ka connection coordinate geometry se!
499 CE
⭐ Āryabhaṭa — Sky ka Coordinate Mapper
Āryabhaṭa ne Greek "chords" ko "sines" se replace kiya — jisse stars aur cities ke coordinates calculate karna bahut aasaan ho gaya. Unhone Celestial Coordinates use karke poora sky map kiya. Sine (sin) function jo aaj Class 10 mein padhoge — woh Āryabhaṭa ki den hai!
628 CE
🔢 Brahmagupta — Zero aur Negative Numbers
Brahmagupta ne zero (0) aur negative numbers ko formal algebraic entities ke roop mein define kiya. Bina negative numbers ke four-quadrant Cartesian plane possible hi nahi hota! Jab hum x = −3 likhte hain, yeh Brahmagupta ki den hai. Origin "0" bhi unka concept hai.
~1000 CE
🔭 Al-Bīrūnī — Astrolabe Perfecter
Arab scholar Al-Bīrūnī India aaye, Siddhāntas padhe, aur Indian trigonometry use karke thousands of cities ke coordinates calculate kiye. Unhone Astrolabe perfect kiya — ek handheld device jo sailors ko stars dekh ke apni coordinates find karne mein help karta tha. GPS ka ancestor!
1637 CE
📊 René Descartes — Final Formalisation
Fermat ke kaam ke baad, French mathematician Descartes ne formally establish kiya ki any 2D point ko sirf 2 numbers se define kiya ja sakta hai — perpendicular axes se distance. Isliye ise "Cartesian" plane bolte hain (Descartes ke naam par). Geometry aur algebra finally formally mile!

🎯 Key Takeaway — History se Lesson

Coordinate system ek collaborative human achievement hai — India → Arabia → Europe ka intellectual journey. Brahmagupta ka zero, Āryabhaṭa ka sine, Baudhāyana ka theorem — inka contribution coordinate geometry mein directly hai. Yeh apna Indian pride hai!

Section 1.3 — 2D Cartesian Coordinate System
The Main Engine of Coordinate Geometry

Class 7-8 mein tumne Number Line padhi thi — jo 1-dimensional thi (sirf ek line par numbers). Ab hum 2-dimensional (2D) plane mein kaam karenge — jahan hum kisi bhi point ko uniquely locate kar sakte hain.

Definition: 2D Cartesian Coordinate System ek aise framework ko kaha jaata hai jisme do perpendicular (90° par) lines use karke 2D space mein kisi bhi point ki exact location batayi ja sakti hai numbers ke zariye.

📏 X-axis (Horizontal)

Seedhi horizontal line. Origin ke right side positive numbers (+1, +2, +3…) aur left side negative numbers (−1, −2, −3…).

📏 Y-axis (Vertical)

Seedhi vertical line. Origin ke upar (upward) positive numbers (+1, +2, +3…) aur neeche (downward) negative numbers (−1, −2, −3…).

⭕ Origin O (0, 0)

X-axis aur Y-axis ka intersection point. Coordinates hain (0, 0). Ye reference point hai — sari distances isi se measure hoti hain. Brahmagupta ka zero concept yahan apply hota hai.

✈️ Coordinate Axes

"Axis" ka plural "Axes" hai. X-axis aur Y-axis milkar Coordinate Axes banate hain. Ye do axes milkar poori 2D plane ko define karte hain.

⚠️ CRITICAL Rule — Yaad Rakhna Zaroori Hai!

  • P(x, y) — x PEHLE aata hai, y BAAD MEIN — ye order change mat karo!
  • P(3, 5) aur P(5, 3) ALAG ALAG POINTS hain — same nahi!
  • Agar x = y ho, tabhi P(x,y) = P(y,x) hoga. Jaise P(4,4) = P(4,4).
  • X-axis par har point ka y-coordinate = 0 hota hai.
  • Y-axis par har point ka x-coordinate = 0 hota hai.

General Form of Coordinates

P = (x, y)
X-axis par koi point: P = (x, 0)
Y-axis par koi point: P = (0, y)
Origin: O = (0, 0)

x = y-axis se perpendicular distance (along x-axis) | y = x-axis se perpendicular distance (along y-axis)

Ek easy trick yaad karo: "All Students Take Classes"

Plotting Points — Graph par Point Kaise Mark Karein?
Step-by-step method with practice

Coordinates di hui hain — graph par point mark karna seekhte hain. Ye CBSE board exam mein direct marks aata hai!

METHOD: "Walk then Climb" Technique

Imagine karo tum Origin O(0,0) par khade ho. Point P(x, y) tak pahunchne ke liye:

  1. X-axis par chalo: x positive hai toh right jao, x negative hai toh left jao, |x| units
  2. Wahan se vertical chalo: y positive hai toh upar jao, y negative hai toh neeche jao, |y| units
  3. Point mark karo: Jahan ruke — wahi tumhara point hai!

📍 Example: Point A(3, 4) plot karo

Step 1: x = 3 (positive) → Origin se 3 units right jaao x-axis par → (3, 0) par pohoncho

Step 2: y = 4 (positive) → Wahan se 4 units upar jaao → (3, 4) par pohoncho

Step 3: Yahan dot lagao aur A(3,4) likho ✓

💡 Dashed lines (dotted lines) bhi draw kar sakte ho — ek x-axis se vertical, ek y-axis se horizontal — dono jahan mile, wahi point hai!

📍 Example: Point Q(−5, 3) plot karo

Step 1: x = −5 (negative) → Origin se 5 units LEFT jaao x-axis par → (−5, 0) par pohoncho

Step 2: y = 3 (positive) → Wahan se 3 units UPAR jaao → (−5, 3) par pohoncho

Step 3: Yahan dot lagao aur Q(−5,3) likho ✓ → Quadrant II mein hai

📍 Example: Point S(3, −5) plot karo

Step 1: x = 3 (positive) → Origin se 3 units RIGHT jaao → (3, 0)

Step 2: y = −5 (negative) → Wahan se 5 units NEECHE jaao → (3, −5)

Step 3: Dot lagao aur S(3,−5) likho ✓ → Quadrant IV mein hai

Section 1.4 — Distance Formula
Do points ke beech ki doori — The Most Important Formula

Ye chapter ka sabse important concept hai aur CBSE exams mein har saal aata hai. Do points ke beech ki distance nikalni ho toh Distance Formula use karte hain.

Pehle simple cases dekhte hain, phir general formula:

📏 Case 1: Points on X-axis

Points (x₁, y) aur (x₂, y) — same y-coordinate
Distance = |x₂ − x₁|
Example: (3, 0) se (7, 0) tak = |7−3| = 4 units

📏 Case 2: Points on Y-axis

Points (x, y₁) aur (x, y₂) — same x-coordinate
Distance = |y₂ − y₁|
Example: (0, 2) se (0, 8) tak = |8−2| = 6 units

Ab general case — jab do points kisi bhi jagah hon:

🔥 Distance Formula — THE MAIN FORMULA

d = √[ (x₂ − x₁)² + (y₂ − y₁)² ]

Jahan: P₁ = (x₁, y₁) aur P₂ = (x₂, y₂) hain
Note: (x₂−x₁)² aur (y₂−y₁)² hamesha positive hote hain (square hai) — toh positive ya negative values se koi fark nahi padta!

💡 Ye Formula Kahan Se Aaya? — Derivation (Samajhna Zaruri Hai)

Ye formula actually Baudhāyana–Pythagoras Theorem ka direct application hai!

Socho: Do points A(x₁, y₁) aur D(x₂, y₂) hain. Inke beech ek right triangle banao:

→ Point F(x₁, y₂) banao (A se vertical, D se horizontal)

→ AF = |y₂ − y₁| (vertical side)

→ FD = |x₂ − x₁| (horizontal side)

→ AD = hypotenuse = √(AF² + FD²) = √[(x₂−x₁)² + (y₂−y₁)²]

Simple terms mein: Horizontal shift² + Vertical shift² = Distance²

Fig 1.7 — A(3,4) se D(7,1) tak distance nikalna — Right Triangle method

📐 NCERT Example — Triangle ADM ke sides nikalo

Given: A(3,4), D(7,1), M(9,6)

AD nikalo:

CD = x_D − x_A = 7 − 3 = 4 (horizontal shift)

AC = y_A − y_D = 4 − 1 = 3 (vertical shift)

AD = √(4² + 3²) = √(16 + 9) = √25 = 5 units ✓

DM nikalo:

x-shift = 9 − 7 = 2 | y-shift = 6 − 1 = 5

DM = √(2² + 5²) = √(4 + 25) = √29 units

MA nikalo:

x-shift = 3 − 9 = −6 (or |−6| = 6) | y-shift = 4 − 6 = −2 (or |−2| = 2)

MA = √(6² + 2²) = √(36 + 4) = √40 = 2√10 units

🌟 More Examples — Practice karo!

Ex 1: A(0,0) se B(3,4) tak:
d = √[(3−0)² + (4−0)²] = √[9+16] = √25 = 5 units

Ex 2: P(−3,−4) se Q(0,0) tak:
d = √[(0−(−3))² + (0−(−4))²] = √[3²+4²] = √[9+16] = √25 = 5 units

Ex 3: R(1,2) se S(4,6) tak:
d = √[(4−1)² + (6−2)²] = √[9+16] = √25 = 5 units

💡 Teen alag alag triangles — phir bhi distance 5! Ye Pythagorean triplet (3,4,5) ka kaal hai.

⚠️ Common Mistakes — Exam mein Ghalti Mat Karna!

  • (x₂−x₁)² mein pehle subtract karo, phir square karo — ye hamesha positive aayega.
  • √ ke andar + hota hai, not minus: √[(x₂−x₁)² + (y₂−y₁)²]
  • Distance hamesha positive hoti hai — answer kabhi negative nahi aana chahiye.
  • Order matter nahi karta: d(A,B) = d(B,A) — formula dono taraf se same result deta hai.

Important Special Cases

Distance from Origin O(0,0) to P(x, y) = √(x² + y²)
Distance between (x₁, 0) and (x₂, 0) on X-axis = |x₂ − x₁|
Distance between (0, y₁) and (0, y₂) on Y-axis = |y₂ − y₁|

Origin se distance ka formula yaad karo — CBSE exam mein circles ke questions mein ye directly kaam aata hai!

Section 1.4 cont. — Reflection (Pratibimb)
Mirror Image in Axes — Ek Important Concept

Jab kisi point ya shape ko axis ke baare mein "reflect" karte hain, toh uska mirror image milta hai. Jaise bathroom mirror mein apna chehera dekhte ho — exact same shape, par left-right reverse.

🪞 Reflection in Y-axis

Point P(x, y) ka Y-axis mein reflection:
P'(−x, y)
x-coordinate ka sign change hota hai, y same rehta hai.
Example: A(3,4) → A'(−3,4)

🪞 Reflection in X-axis

Point P(x, y) ka X-axis mein reflection:
P'(x, −y)
y-coordinate ka sign change hota hai, x same rehta hai.
Example: A(3,4) → A''(3,−4)

🪞 Reflection in Origin

Point P(x, y) ka origin mein reflection:
P'(−x, −y)
Dono coordinates ka sign change.
Example: A(3,4) → A'''(−3,−4)

📐 NCERT Example — Triangle ADM ka Y-axis mein Reflection

Original points: A(3,4), D(7,1), M(9,6)

Y-axis mein reflect karne ke baad: A'(−3,4), D'(−7,1), M'(−9,6)

Distances check karo:

A'D' = √[(−3−(−7))² + (4−1)²] = √[4²+3²] = √25 = 5 units

Pehle AD bhi 5 tha! ✓

D'M' = √[(−7−(−9))² + (1−6)²] = √[2²+5²] = √29 units (same as DM ✓)

M'A' = √[(−9−(−3))² + (6−4)²] = √[6²+2²] = √40 units (same as MA ✓)

Conclusion: Reflection distances preserve karti hai — Shape aur size same rehte hain, bas position change hoti hai!

🎯 Key Properties of Reflection — Yaad Rakhne Wali Baat

  • Reflection ke baad distances preserved rehti hain (same lengths)
  • Shape aur size same rehte hain — congruent shapes bante hain
  • Orientation reverse ho jaata hai (left becomes right, etc.)
  • Area bhi same rehta hai
  • Axis of reflection ke baare mein har point ki distance equal rehti hai

Midpoint Concept — Beech ka Point Kaise Nikaalein?
Section Formula ka Foundation (★ Starred Questions)

NCERT mein starred (*) questions hain jo midpoint ke baare mein hain. Ye Class 10 mein formal form mein aayega ("Section Formula"), par Class 9 mein concept samajhna hai.

Midpoint Formula

M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )

Agar M segment ST ka midpoint hai (S=(x₁,y₁) aur T=(x₂,y₂)), toh M ke coordinates hain dono x-coordinates ka average aur dono y-coordinates ka average.

📊 NCERT Exercise Table — Midpoint Check

SMTM midpoint hai?Reason
(−3,0)(0,0)(3,0)✓ Yes(−3+3)/2=0, (0+0)/2=0 → M=(0,0) ✓
(2,3)(3,4)(4,5)✓ Yes(2+4)/2=3, (3+5)/2=4 → M=(3,4) ✓
(0,0)(0,5)(0,−10)✗ No(0+0)/2=0, (0+(−10))/2=−5 → M should be (0,−5) not (0,5)
(−8,7)(0,−2)(6,−3)✗ No(−8+6)/2=−1, (7+(−3))/2=2 → M should be (−1,2) not (0,−2)

⭐ Starred Example — Find B, given Midpoint M

Problem: M(−7, 1) is midpoint of A(3, −4) and B(x, y). Find B.

Solution:

Midpoint formula se: (3+x)/2 = −7 → 3+x = −14 → x = −17

(−4+y)/2 = 1 → −4+y = 2 → y = 6

Answer: B(−17, 6)

⭐ Trisection Points — A(4,7) aur B(16,−2) ke trisection points nikalo

P aur Q trisection points hain, P A ke paas, Q B ke paas.

Step 1: P midpoint hai AP aur PQ ka — lekin easier method: P beech mein hoga ⅓ distance par.

Shortcut: Pehle find karo M = midpoint of AB = ((4+16)/2, (7+(−2))/2) = (10, 2.5)

Phir: P = midpoint of AM = ((4+10)/2, (7+2.5)/2) = (7, 4.75)

Q = midpoint of MB = ((10+16)/2, (2.5+(−2))/2) = (13, 0.25)

Q3: R(3,0), A(0,−2), M(−5,−2), P(−5,2) — RAMP join karo. Perpendicular sides? Parallel to axis? Mirror images?
(i) Perpendicular sides: MP aur MA — MP is vertical (same x=−5), MA connects different quadrants

Q12(i): A(1,−8), B(−4,7), C(−7,−4) — show karein ye circle K (center O) par hain, radius kya?
OA = √(1²+(−8)²) = √(1+64) = √65
OB = √((−4)²+7²) = √(16+49) = √65
OC = √((−7)²+(−4)²) = √(49+16) = √65
OA = OB = OC = √65 — teeno same distance par hain! → Radius = √65 units ✓
Q12(ii): D(−5,6) aur E(0,9) — circle ke andar, par, ya bahar?
OD = √(25+36) = √61 < √65 → D is INSIDE the circle
OE = √(0+81) = √81 = 9 | √65 ≈ 8.06 < 9 → OE > radius → E is OUTSIDE the circle
Q15: Screen 800×600 pixels. Circle A(100,150) radius 80, Circle B(250,230) radius 100. Circles screen ke bahar jaati hain? Intersect karti hain?
Circle A screen mein?
Left: 100−80=20 > 0 ✓ | Right: 100+80=180 < 800 ✓ | Bottom: 150−80=70 > 0 ✓ | Top: 150+80=230 < 600 ✓ → Fully inside ✓
Circle B screen mein?
Left: 250−100=150>0 ✓ | Right: 250+100=350<800 ✓ | Bottom: 230−100=130>0 ✓ | Top: 230+100=330<600 ✓ → Fully inside ✓
Circles intersect?
d(A,B) = √[(250−100)²+(230−150)²] = √[150²+80²] = √[22500+6400] = √28900 = 170
r₁+r₂ = 80+100 = 180 | |r₁−r₂| = 20
20 < 170 < 180 → Circles intersect (overlap karte hain)! ✓
Q16: A(2,1), B(−1,2), C(−2,−1), D(1,−2) — ABCD square hai? Area?
AB = √[(−1−2)²+(2−1)²] = √[9+1] = √10
BC = √[(−2−(−1))²+(−1−2)²] = √[1+9] = √10
CD = √[(1−(−2))²+(−2−(−1))²] = √[9+1] = √10
DA = √[(2−1)²+(1−(−2))²] = √[1+9] = √10
Sab sides equal = √10!
Diagonal AC = √[(−2−2)²+(−1−1)²] = √[16+4] = √20 = 2√5
Diagonal BD = √[(1−(−1))²+(−2−2)²] = √[4+16] = √20 = 2√5
Diagonals bhi equal! ABCD is a Square ✓

1. COORDINATES OF BASIC POINTS

Origin: O = (0, 0)
X-axis par: P = (x, 0) — y = 0 hamesha
Y-axis par: P = (0, y) — x = 0 hamesha

2. QUADRANT SIGN RULES

Q-I: (+, +) | Q-II: (−, +) | Q-III: (−, −) | Q-IV: (+, −)

3. DISTANCE FORMULA ⭐ (Sabse Important)

d(P₁P₂) = √[ (x₂ − x₁)² + (y₂ − y₁)² ]
d(O, P) = √(x² + y²) [Distance from Origin]
d on x-axis: |x₂ − x₁|
d on y-axis: |y₂ − y₁|

4. REFLECTION FORMULAS

Reflection in Y-axis: (x, y) → (−x, y)
Reflection in X-axis: (x, y) → (x, −y)
Reflection in Origin: (x, y) → (−x, −y)

5. MIDPOINT FORMULA ⭐ (★ Starred)

M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )

6. COORDINATE PROPERTIES

P(x,y) = P(y,x) only if x = y
If x ≠ y, then P(x,y) ≠ P(y,x)

  • Quadrant signs: I=(+,+), II=(−,+), III=(−,−), IV=(+,−)
